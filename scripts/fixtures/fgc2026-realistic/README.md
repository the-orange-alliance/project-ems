# FGC 2026 realistic statistics fixtures

These databases are generated by `scripts/generate-fgc2026-realistic-fixtures.mjs`.

- `fgc2026-realistic-partial.db`: 180 teams, 150 scheduled qualification matches, the first 75 (50%) played.
- `fgc2026-realistic-full.db`: the same event with all 150 matches played.

Every team appears in exactly five qualification matches (five balanced rounds of
30 matches). Match rosters are deterministic. Scores, penalties, wildfire counts,
and brace/climb states are seeded pseudo-random values drawn from plausible
ranges; match scores and rankings are then computed by the real `fgc_2026`
season code in `@toa-lib/models`, so matches 1-75 are identical between the two
databases.

Re-run the generator from the repository root:

```text
node scripts/generate-fgc2026-realistic-fixtures.mjs
```

Each run also:

- copies both databases into the EMS app-data directory as
  `fgc2026_realistic_partial.db` / `fgc2026_realistic_full.db` (the file names
  the server loads them by), removing any stale `.stats.db` cache alongside them;
- upserts both events into `global.db` (`seasonKey = fgc_2026`, `regionKey =
  TEST`) so the API, stats, and graphics services recognize them.

Restart the API and realtime services after regenerating so they pick up the
refreshed `global.db` and database files.
